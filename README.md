# WHAT-TO-EAT-AGENT

An intelligent meal-planning assistant combining RAG and MCP components.

Quick start

1. (Optional) Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt` (or see `pyproject.toml`).
3. Run the app: `python main.py`.

Notes

- This repository contains local SQLite DBs under `data/db/`. Those are ignored by default.
- To publish to GitHub, create a repo and push the local git repository.
